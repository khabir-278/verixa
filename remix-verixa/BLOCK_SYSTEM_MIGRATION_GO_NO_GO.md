4. **Whether `is_blocked` and related RPCs expose block relationships or permit enumeration:**
   - **PASS (Local SQL Verified in `T22`):** `public.is_blocked(user_a, user_b)` (`up.sql:155-204`) returns `TRUE` (**fail-closed**) whenever `user_a IS NULL OR user_b IS NULL`, or when a non-privileged caller (`v_caller`) is neither `user_a` nor `user_b`. Thus `NOT public.is_blocked(...)` evaluates to `FALSE` (denying access) and third-party callers cannot enumerate whether User X blocked User Y. `REVOKE ALL ON FUNCTION public.is_blocked(UUID, UUID) FROM PUBLIC, anon;` revokes anonymous execution. Similarly, `public.get_my_restricted_user_ids()` (`up.sql:211-244`) only returns user IDs mutually restricted with `auth.uid()` and never exposes `reason` or third-party rows.
5. **Whether message updates, stories, reels, follows, likes, comments, and privileged functions enforce ownership and mutual-block rules:**
